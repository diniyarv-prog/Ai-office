# AI Office Memory Sync

Цель: сделать поток памяти для AI Office:

```text
Telegram-группа AI Office → GitHub-репозиторий → локальная машина Динияра
```

## Что синхронизируем

Не весь чат подряд, а полезную память:

- решения по AI Office;
- правила агентов;
- описания вкладок;
- устойчивые предпочтения Динияра;
- рабочие инструкции;
- промпты и шаблоны;
- заметки, которые Динияр явно просит сохранить.

## Что НЕ синхронизируем

- мусорные сообщения;
- временные обсуждения;
- секреты/API ключи;
- финансовые операции целиком;
- личную терапевтическую сырьёвую переписку без явной команды сохранить;
- токены, chat_id, приватные ссылки.

## Текущий GitHub blocker

На сервере сейчас нет настроенного `gh`/GitHub auth и workspace не является git-репозиторием.

Чтобы включить GitHub sync, нужно одно из двух:

1. Динияр даёт готовый GitHub repo URL, куда можно пушить.
2. Или на сервере авторизуем GitHub CLI / токен.

После этого поток:

```bash
git add memory/ config/ README.md
git commit -m "update ai office memory"
git push origin main
```

## Локальная машина

На Mac Динияра:

```bash
git clone <repo-url> ~/AI-Office-Memory
cd ~/AI-Office-Memory
git pull
```

Дальше локальные агенты/Claude Code могут читать:

- `memory/ai-office.md`
- `memory/agents.md`
- `memory/preferences.md`
- `config/telegram-topics.json`

## Правило обновления

Сначала GitHub как источник правды, потом локальная машина подтягивает изменения.

Не наоборот, чтобы не было расхождения версий.
